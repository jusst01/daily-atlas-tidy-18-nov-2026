# News Image 18 November 2026

A one-page newspaper image summing up Wednesday 18 November 2026 in 55 stories, drawn procedurally with Pillow by `draw.py` and deployed by `main.py`.

## Run it

```bash
python3 -m venv .venv
.venv/bin/pip install pillow
.venv/bin/python draw.py
python3 main.py
```
